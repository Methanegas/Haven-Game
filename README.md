# Epik Blob Game 7
## by Violet and Vishwesh

# Description
A 3d Godot game where a slime ball whimsically collects cheese blocks.
Realtime soft-body physics.

## Controls
Move with WASD, jump with spacebar, dash with shift, and grapple with right-click.
